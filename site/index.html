KaraDial

A browser extension that replaces your new tab page with the bookmarks from your self-hosted Karakeep instance.

Get the latest release Source code

What it does

  • Each Karakeep list you pick becomes one page of tiles, child lists become groups.
  • Typing filters your pages at once. Enter searches all of Karakeep.
  • Opens instantly from a local cache and keeps working when the server is down.
  • Tiles your way: size or your own columns, spacing and width, how preview images fit, which texts they show.
  • Order tiles as in Karakeep, by date, by title, or by hand with drag and drop.
  • Privacy mode hides your bookmarks while you share your screen. Hold Esc for a second to switch it.
  • Full keyboard navigation, light and dark theme.

Install

KaraDial runs in Firefox 140 or later and in Firefox based browsers such as Zen. Open the signed .xpi file from the latest release in the browser. It updates itself from this site. Then enter the address of your Karakeep instance and a read-only API key in the options.

Privacy

KaraDial talks only to the Karakeep instance you configure. It sends your API key and, when you search all of Karakeep, your search terms to that instance and nowhere else. No analytics, no telemetry, no remote code.
